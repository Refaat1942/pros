# النماذج الرسمية المعتمدة

## عرض الأسعار — `quote-form.jpg`

النموذج المعتمد لطباعة عرض السعر (نسخة مرجعية — **بيانات المريض واسم الموقّع محجوبة عمداً**).
يُطبع من النظام عبر `resources/views/quotes/print.blade.php` بنفس الترتيب، وتظهر له معاينة حية في **مركز الوثائق** (ويمكن تخصيص نصوصه لكل قسم/مرحلة):

| جزء النموذج | مصدره في النظام |
|---|---|
| أسطر الترويسة + الشعار | الإدارة ← الهوية البصرية (أسطر الترويسة / الشعار)، وإظهار الشعار/الختم من مركز الوثائق |
| تاريخ عرض السعر | `quotes.quote_date` |
| مدة سريان عرض السعر | الإدارة ← مركز الوثائق ← «عرض سعر» |
| الجهة | جهة التعاقد على العرض (أو «نقدي») |
| الإسم | الرتبة / اسم المريض |
| السن | محسوب من الرقم القومي للمريض |
| نوع الإصابة | التشخيص في آخر كشف طبي للحالة |
| تاريخها | يُترك للكتابة اليدوية (غير مسجل في النظام) |
| البيان / المكونات — المواصفات التفصيلية | الوصف الحر من التوصيف الفني (سطر بصيغة `المكوّن: التفاصيل`)، وإلا بنود قائمة المواد مجمّعة حسب «المجموعة» |
| مدة التوريد / الضمان | الإدارة ← مركز الوثائق ← «عرض سعر» |
| الإجمالي قبل الخصم / نسبة الخصم / بعد الخصم | خصم جهة التعاقد على عرض السعر |
| التوقيع (الاسم والصفة) | الإدارة ← مركز الوثائق ← «عرض سعر» |
| التذييل (التليفونات / العنوان / الموقع) | الإدارة ← مركز الوثائق ← «عرض سعر» |

> رمز QR ورقم عرض السعر يظهران بجوار الشعار — مطلوبان لمسح العرض في الاستقبال.
