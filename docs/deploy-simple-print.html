Part A — At home (with internet) — prepare USB

  1. Download Laragon Full → laragon.org/download
  2. Download Git (optional) → git-scm.com/download/win
  3. On your PC with Laragon, run:
cd C:\laragon\www git clone https://github.com/Refaat1942/pros.git prosthetics cd prosthetics git pull origin master composer install --no-dev --optimize-autoloader
Important: Copy the whole folder C:\laragon\www\prosthetics to USB. It must include the vendor folder. Without it, the system will not work offline.

Part B — At the client — the server PC

Step 1 — Choose the server computer

  • One Windows PC that stays ON during work hours
  • Connect a UPS (battery backup) if possible
  • Ask IT for a fixed IP (example: 192.168.1.50)

Step 2 — Install Laragon

  1. Run Laragon installer from USB → install to C:\laragon
  2. Open Laragon → click Start All (Apache must be green)

Step 3 — Install PostgreSQL (database)

  1. Laragon → Menu → PostgreSQL → Install
  2. Click Start All again

PostgreSQL = where all patient and system data is stored.

Copy project & create database

Steps 4–7
Page 2 / 4

Step 4 — Copy the project from USB

Copy folder to: C:\laragon\www\prosthetics

Check inside: folders vendor, public, file .env.example

Step 5 — Create database (one time)

Laragon → Menu → PostgreSQL → psql (black window opens)

Paste this (change the password!):

CREATE DATABASE prosthetics ENCODING 'UTF8' LC_COLLATE 'C' LC_CTYPE 'C' TEMPLATE template0; CREATE USER prosthetics_user WITH PASSWORD 'StrongPassword2026!ChangeMe'; GRANT ALL PRIVILEGES ON DATABASE prosthetics TO prosthetics_user; \c prosthetics GRANT ALL ON SCHEMA public TO prosthetics_user; GRANT CREATE ON SCHEMA public TO prosthetics_user; \q

\q = exit. Write the same password in Step 6.

Step 6 — Edit settings file (.env)

Open Command Prompt (search "cmd") and type:

cd C:\laragon\www\prosthetics copy .env.example .env php artisan key:generate notepad .env

In Notepad, change these lines (use real server IP):

APP_URL=http://192.168.1.50 APP_DEBUG=false DB_DATABASE=prosthetics DB_USERNAME=prosthetics_user DB_PASSWORD=StrongPassword2026!ChangeMe SESSION_SECURE_COOKIE=false TELEGRAM_ERROR_NOTIFY=false FIREBASE_ENABLED=false

Save and close Notepad.

Step 7 — Start the system (run once)

cd C:\laragon\www\prosthetics php artisan migrate --force php artisan db:seed --class=Database\Seeders\RolesAndAdminSeeder php artisan storage:link php artisan config:cache
CommandWhat it does (simple)
migrateCreates empty tables in the database
db:seed RolesAndAdminSeederCreates login accounts (admin, reception, doctor…)
storage:linkLets system save uploaded files
config:cacheSaves settings for faster running
Do NOT run full php artisan db:seed — it adds fake demo patients. Use RolesAndAdminSeeder only.

Login, network & staff PCs

Steps 8–11
Page 3 / 4

Step 8 — First login (on server)

  1. Open Chrome
  2. Go to: http://prosthetics.test OR http://YOUR-IP/prosthetics/public
  3. Login: username superadmin · password 123456
  4. Change password immediately!

Step 9 — Test from another computer

On another PC on the same network, open Chrome:

http://192.168.1.50/prosthetics/public

(Replace with your real server IP)

If it does not work:

  • Server is ON and Laragon → Start All (green)
  • Windows Firewall: allow Apache on Private network (ask IT)
  • Wrong IP — run ipconfig on server, find IPv4 Address

Step 10 — Staff computers (easy)

On each staff PC — nothing to install:

  1. Open Chrome → go to the link above
  2. Bookmark (Ctrl+D)
  3. Optional: desktop shortcut named "Prosthetics ERP"

Step 11 — Backup (important)

Test once on server:

cd C:\laragon\www\prosthetics php artisan prosthetics:backup

Backup files: C:\laragon\www\prosthetics\storage\backups

Schedule daily at 2:00 AM (Task Scheduler) or copy folder to USB weekly.

Checklists & troubleshooting

Print and use on site
Page 4 / 4

Before visit checklist

  • USB has Laragon installer
  • USB has full prosthetics folder (with vendor)
  • Wrote client name, date, your phone number

On server checklist

  • Laragon installed → Start All green
  • PostgreSQL installed → Start All green
  • Project in C:\laragon\www\prosthetics
  • Database created (Step 5)
  • .env edited (IP + password)
  • Step 7 commands finished OK
  • Login works on server
  • Login works from another PC
  • superadmin password changed

Staff handover checklist

  • Gave everyone the link
  • Created real user accounts (not default 123456)
  • Backup tested
  • Client knows: do not turn off server during work hours

If something breaks

ProblemTry this
Blank page / errorLaragon → Stop All → Start All
Cannot open from another PCCheck IP, Firewall, server is ON
Database error (red text)Password in .env must match Step 5
After power cutTurn server ON → Laragon → Start All

Later update (when internet is back — server only)

cd C:\laragon\www\prosthetics git pull origin master composer install --no-dev --optimize-autoloader php artisan migrate --force php artisan config:cache

Tell staff: press Ctrl + F5 in Chrome.
