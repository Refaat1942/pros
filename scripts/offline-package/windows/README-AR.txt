نظام مركز الأطراف الصناعية — باكدج الأوفلاين
=================================================
الباكدج دي فيها البرنامج كامل بكل مكتباته. جهاز العميل مش محتاج نت ولا GitHub ولا composer.

أولاً: التحديث (السيرفر شغال عليه النظام بالفعل)
-------------------------------------------------
1) انقل ملف الـ ZIP للجهاز (فلاشة).
2) كليك يمين على الملف ← Extract All (فك الضغط كامل).
3) شغّل Laragon (Start All) — لازم PHP 8.3 أو أحدث (من قائمة Laragon ← PHP ← Version).
4) افتح المجلد اللي اتفك ودوس دبل كليك على UPDATE.bat
   (لو قال php مش موجود: من Laragon اضغط Terminal واكتب مسار الملف، مثال:
    "C:\Users\...\Downloads\prosthetics-offline-...\UPDATE.bat")
5) استنى لحد ما يظهر DONE، وبعدين المستخدمين يضغطوا Ctrl+F5.

التحديث بيعمل لوحده: نسخة احتياطية ← نسخ الملفات ← تحديث قاعدة البيانات ← الصلاحيات ← الكاش.
محفوظ ومش بيتلمس: ملف .env، والمرفقات، والنسخ الاحتياطية (مجلد storage).
لو النظام في مجلد غير C:\laragon\www\prosthetics:
   UPDATE.bat "D:\المسار\prosthetics"

ثانياً: التسطيب لأول مرة (جهاز جديد)
-------------------------------------
1) ثبّت Laragon وشغّله (Start All).
2) فك ضغط الباكدج ودوس دبل كليك على INSTALL.bat
3) هيسألك عن اسم قاعدة البيانات واسم مستخدم MySQL والباسورد (اضغط Enter للقيم الافتراضية في Laragon)،
   وبعدها كلمة مرور الحساب الرئيسي (superadmin) — من غير الرموز & أو % أو ^.
4) بعد ما يظهر INSTALLED ادخل بـ superadmin والباسورد اللي اخترته.

لو حصل أي خطأ: صوّر الشاشة وابعتها.
